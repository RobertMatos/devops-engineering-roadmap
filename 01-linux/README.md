
# 01 - Linux Administration

## Overview

This module covers Linux fundamentals and server administration,
focusing on practical skills required for DevOps engineering.

## Learning Objectives

- Understand Linux architecture and distributions.
- Navigate and manage the Linux filesystem.
- Manage users, groups and permissions.
- Monitor processes and system resources.
- Manage services with systemd.
- Analyze logs and troubleshoot issues.
- Understand networking and SSH.
- Perform basic server administration.
